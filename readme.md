# 📁 Document Archive Management System

Système de gestion d'archives documentaires avec OCR, recherche sémantique et assistant IA (RAG).

---

## 🚀 Démarrage rapide

### Prérequis

- **Docker Desktop** installé et démarré
- Au moins **8 GB de RAM** (16 GB recommandé pour Ollama)
- Au moins **10 GB d'espace disque** libre
- **Windows 10/11**, **macOS** ou **Linux**

### Installation (2 étapes)

#### 1. Cloner le projet

```bash
git clone <votre-repo-url>
cd Stage-2éme
```

#### 2. Start Docker

```bash
./start_docker.ps1
```

#### Fonctionnalités

🔐 Authentification JWT avec rôles (Admin, Archivist, Employee)

📄 Upload de documents (PDF, Word, Excel, Images)

🔍 OCR pour les documents scannés (Tesseract)

🧠 Recherche sémantique avec Qdrant

💬 Assistant IA avec RAG (Llama 3.2)

📁 Gestion des départements

📦 Gestion des boîtes d'archives

📊 Tableau de bord

📝 Journal d'activité
